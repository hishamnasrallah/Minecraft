# BlockWorld

لعبة sandbox ثلاثية الأبعاد بالبلوكات، مكتوبة بـ Python باستخدام [Ursina](https://www.ursinaengine.org/). بتشتغل محلياً على جهازك.

A small 3D voxel sandbox written in Python with the Ursina engine. Runs locally.

## التشغيل / Run

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py                   # يكمل من آخر حفظ
python main.py --new             # عالم جديد
python main.py --creative        # كل البلوكات بدون عدّ، وبدون صحة وجوع
```

## التحكم / Controls

| المفتاح | الوظيفة |
|---|---|
| WASD + الماوس | حركة ونظر |
| Space | قفز / سباحة لفوق بالمي |
| اضغط مطوّل كليك يسار | تكسير بلوك (بالـ creative كليك وحدة بتكفي) |
| كليك يمين | وضع بلوك، أو أكل إذا ماسك أكل |
| كليك يسار على حيوان | ضربة (الفاس أقوى سلاح) |
| R | إعادة الإحياء بعد الموت |
| 1-9 أو عجلة الماوس | اختيار خانة من الشريط |
| E | فتح/سكّر الـ inventory والـ crafting |
| T | تسريع الوقت ×40 (تشغيل/إيقاف) |
| F5 | حفظ |
| Esc | سكّر الـ inventory، أو حفظ وخروج |

### بالـ inventory

| | |
|---|---|
| كليك يسار | شيل/حط stack كامل، أو بدّل |
| كليك يمين | شيل نص الـ stack، أو حط وحدة |
| Shift + كليك يسار | انقل الـ stack بين الشريط والمخزن |
| كليك على وصفة | اصنعها مرة (Shift = لحد 16 مرة) |

## البنية / Structure

- `world.py` — بيانات العالم، توليد التضاريس (noise)، بناء الـ mesh لكل chunk، الحفظ والتحميل. بدون أي اعتماد على Ursina عشان يتجرّب بسهولة.
- `inventory.py` — الأغراض والأدوات، الـ inventory (36 خانة، stack لحد 64)، الوصفات، صلابة البلوكات وشو بيطلع من كل بلوك لما تكسره.
- `animals.py` — سلوك الحيوانات وحركتها وظهورها (بدون Ursina، فبيتجرّب).
- `animal_models.py` — أشكال الحيوانات المبنية من مكعبات.
- `survival.py` — الصحة والجوع والنفَس والوقعات والموت (بدون Ursina، فبيتجرّب).
- `lighting.py` — الـ shader اللي بحوّل مستويات الضو للون النهائي.
- `textures.py` — بيرسم textures البلوكات (pixel art) بالكود وبجمعها بصورة وحدة (atlas).
- `main.py` — اللعبة نفسها: العرض، اللاعب، الواجهة، كسر ووضع البلوكات.
- `tests/` — اختبارات `world.py` (`pip install -r requirements-dev.txt && pytest`).

العالم **لا نهائي**: مقسوم لـ chunks حجمها 16×16 بتتولد من الـ seed لما تقرّب منها، والبعيدة بتنشال من الذاكرة.
كل chunk إلها mesh واحدة فيها بس الوجوه الظاهرة، وبتنبنى 2 chunks بكل frame عشان ما يصير تقطيع.
فيه **مي** (بحيرات وبحر لحد مستوى `WATER_LEVEL`) بتقدر تسبح فيها، ولما تكسر بلوك جنب المي بتفيض عليه.
وفيه **كهوف** محفورة بـ 3D noise تحت الأرض، وبعضها إلها مداخل من فوق. `CAVE_THRESHOLD` بيتحكم بكثرتها.
فيه **إضاءة**: كل خلية هوا إلها مستوى ضو من 0 لـ 15. ضو السما بنزل لتحت وبيدخل الكهوف وبيضعف كل بلوك، وتحت المي وتحت الشجر أعتم. **اللمبة** (رقم 9) بتضوي حواليها بضو دافي.
وفيه **ليل ونهار**: يوم كامل كل 10 دقايق (`DAY_LENGTH`)، مع شمس وقمر وغروب، والساعة فوق عاليمين. الضو بيتحسب مرة وحدة لكل chunk، والـ shader (`lighting.py`) بيدمجه مع وقت النهار، فتغيّر الوقت ما بيكلف شي.
## Inventory و Crafting

بتبلّش فاضي. لما تكسر بلوك بيروح عالـ inventory (العشب بيعطي تراب، الفحم الخام بيعطي فحم، والورق أحياناً عصاية)، ولما تحط بلوك بينقص.

| الوصفة | النتيجة |
|---|---|
| 1 خشب | 4 ألواح |
| 2 ألواح | 4 عصي |
| 4 رمل | 2 زجاج |
| 2 تراب + 2 رمل | 2 طوب |
| 4 حجر | 1 طوب |
| 1 فحم + 1 عصاية + 1 زجاج | 2 لمبة |

### الأدوات وسرعة التكسير

كل بلوك إله صلابة، فلازم تضل ضاغط لحد ما ينكسر وبتشوف الشقوق عم تكبر عليه. الأداة الصح بتسرّع:

| البلوك | بالإيد | خشب | حجر | الأداة |
|---|---|---|---|---|
| تراب / رمل | 0.75 ث | | | — |
| خشب / ألواح | 3 ث | 1.5 ث | 0.75 ث | فاس |
| حجر | 7.5 ث وما بيعطي شي | 1.1 ث | 0.6 ث | معول |
| فحم خام | 15 ث وما بيعطي شي | 2.25 ث | 1.1 ث | معول |

| الوصفة | النتيجة |
|---|---|
| 3 ألواح + 2 عصي | معول خشب (60 استعمال) |
| 3 حجر + 2 عصي | معول حجر (130 استعمال) |
| 2 ألواح + 2 عصي | فاس خشب (60 استعمال) |
| 2 حجر + 2 عصي | فاس حجر (130 استعمال) |

الأداة بتستهلك بس لما تستعملها على البلوك تبعها، وفيه شريط تحت الخانة بيورجيك قديش ضايل فيها. أرقام الصلابة والسرعة بـ `inventory.py` (`HARDNESS`, `TOOLS`).

الفحم الخام بتلاقيه بالحجر تحت الأرض وبالكهوف. الزجاج شفاف وبيدخّل الضو.
الوصفات بـ `RECIPES` بـ `inventory.py`، سهل تضيف عليها. أول طريق: اقطع شجرة ← ألواح وعصي ← معول خشب ← احفر حجر ← أدوات حجر.

## الحيوانات

فيه 3 حيوانات بتتحرك بالعالم وبتظهر حواليك (لحد 12 بنفس الوقت)، والبعيدة بتختفي:

| الحيوان | وين بتلاقيه | شو بيعمل |
|---|---|---|
| أرنب | عالعشب | بينطّ، سريع، وبيهرب إذا قرّبت عليه 5 بلوكات |
| غزال | عالعشب | بيمشي على مهل، وبيهرب إذا قرّبت كتير |
| بطة | عالشط وعالمي | بتعوم فوق المي |

كل حيوان بيوقف شوي، بعدين بيمشي لمكان عشوائي، بيطلع درجة بلوك وحدة، وما بيمشي بالمي أو يوقع من علو (إلا البطة). إذا ضربته بيحمرّ وبيقفز لورا وبيهرب، وإذا خلصت صحته بيموت وبيعطيك لحمة نية (الأرنب والبطة 3 صحة، الغزال 8). ضربة الإيد 1، المعول 2، الفاس 3 (خشب) أو 4 (حجر). بيعتموا بالليل وبالظل متل البلوكات.

## الصحة والجوع

فوق الشريط فيه 10 قلوب (الصحة) و 10 أفخاذ (الجوع)، كل وحدة = نقطتين من 20.

- **الجوع** بينزل شوي شوي مع الوقت، وأسرع لما تمشي، تنط، تكسّر أو تضرب. الشريط المليان بيكفي تقريباً 20 دقيقة لعب.
- **الصحة بترجع** لحالها (نقطة كل 4 ثواني) إذا جوعك 18 أو أكتر.
- **الأذى:** الوقعة من أعلى من 3 بلوكات (المي بتلقطك)، الغرق لما يخلص نفَسك (10 ثواني، وبتشوف فقاعات)، والجوع لما يوصل صفر.
- **الأكل:** امسكه وكبس كليك يمين.

| الأكل | بيرجّع |
|---|---|
| لحمة نية (من الحيوانات) | 2 |
| تفاحة (أحياناً من الورق) | 4 |
| لحمة مطبوخة (2 لحمة نية + 1 فحم) | 6 |

لما تموت بتطلعلك شاشة فيها السبب، وبتكبس R لترجع بنقطة البداية بصحة وجوع كاملين. الـ inventory بيضل معك.
الأرقام كلها بـ `survival.py`.
السلوك بـ `animals.py` (`SPECIES` للسرعة والحجم ومسافة الهروب)، والأشكال بـ `animal_models.py`.

الحفظ بخزّن الـ seed والوقت والـ inventory والصحة والجوع ومكانك وتعديلات اللاعب بس، فالتعديلات بترجع لما ترجع لنفس المكان.

إعدادات بأول `main.py`: `RENDER_DISTANCE` (كم chunk حواليك بتنرسم) و `CHUNKS_PER_FRAME`.

## Textures

الـ textures بتنرسم تلقائياً. إذا بدك ترسم تبعتك:

```bash
python textures.py      # بيطلع textures/atlas.png
```

عدّل الصورة بأي برنامج رسم (حافظ على شبكة 5×5 وترتيب `TILES` بـ `world.py`)، واللعبة رح تستخدم نسختك تلقائياً.
