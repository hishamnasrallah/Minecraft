# BlockWorld

لعبة sandbox ثلاثية الأبعاد بالبلوكات، مكتوبة بـ Python باستخدام [Ursina](https://www.ursinaengine.org/). بتشتغل محلياً على جهازك.

A 3D voxel sandbox written in Python with the Ursina engine. Runs locally.

> **نسخة الموبايل (أندرويد):** بمجلد [`godot/`](godot/README.md)، بمحرك Godot. نفس العالم ونفس البيانات.

## التشغيل / Run

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py                   # يكمل من آخر حفظ
python main.py --new             # عالم جديد
python main.py --creative        # يبلّش بالـ creative (وبتقدر تبدّل باللعبة بـ G)
```

## Creative mode

قائمة الـ creative (بالـ E) فيها كل الأغراض باللعبة (141 غرض) مقسومة على تبويبات:
**all · natural · building · colored · plants · functional · tools · food · materials**

| الحركة | النتيجة |
|---|---|
| كليك يسار على غرض | بتشيل stack كامل |
| كليك يمين على غرض | بتشيل وحدة |
| Shift + كليك على غرض | stack كامل مباشرة عالـ inventory |
| مرّر الماوس على غرض واكبس 1-9 | بيروح لهديك الخانة بالشريط |
| كليك عالقائمة وإنت ماسك غرض | بيمسحه |
| خانة **X** | سلة: بتمسح اللي ماسكه، Shift + كليك بتفضّي الـ inventory |
| **search** | بحث بالاسم بكل التبويبات |
| prev / next | الصفحات |
| sunrise / noon / sunset / midnight / freeze time | التحكم بالوقت |

### أدوات البناء بالجملة (creative)

بتأشّر على بلوك وبتكبس:

| المفتاح | الوظيفة |
|---|---|
| Z / X | الزاوية الأولى / التانية للتحديد (بيبيّن صندوق أزرق وحجمه فوق عاليسار) |
| F | تعبئة التحديد بالبلوك اللي بإيدك |
| Shift + F | استبدال: نوع البلوك اللي بتأشّر عليه بيصير البلوك اللي بإيدك (جوا التحديد بس) |
| H | صندوق فاضي: حيطان وأرض وسقف بس |
| Delete | تفضية التحديد |
| C | نسخ |
| اضغط مطوّل V | معاينة صفرا لمكان اللصق، وبتلصق لما تترك (Shift = بيلصق الهوا كمان) |
| R / M | تدوير النسخة 90° / عكسها (الدرج والسلالم والأبواب بيلفّوا معها) |
| U | تراجع عن آخر عملية (لحد 20) |
| Q | إلغاء التحديد (Shift + Q بيمسح النسخة كمان) |

أكبر عملية 32768 بلوك (32×32×32). المنطق كله بـ `building.py`.

### Schematics (حفظ البنايات كملفات)

**L** بيفتح مكتبة البنايات:
- اكتب اسم وكبس **save copy**: النسخة الحالية (اللي عملتها بـ C) بتنحفظ كملف بمجلد `schematics/`.
- كبس على بناية من القائمة: بتصير هي النسخة، وبعدين **V مطوّل** لتحطها وين ما بدك (و R / M لتلفها أو تعكسها).
- **delete** بيمسح الملف.

الملفات JSON صغيرة (البلوكات المكررة بتنضغط)، وبتحفظ أسماء البلوكات مع الأرقام، فبتشتغل بأي عالم وبتقدر تبعتها لصاحبك يحطها بمجلد `schematics/` عنده. فيه مثال جاهز: `small_house`.

### الشرائط المحفوظة

9 شرائط محفوظة: بالـ creative menu صف **hotbars**، كليك = تحميل، Shift + كليك = حفظ. أو من الكيبورد: **Alt + رقم** تحميل، **Alt + Shift + رقم** حفظ. بينحفظوا مع اللعبة.

وكمان بالـ creative: بلوكات وأدوات ما بتخلص، تكسير فوري (حتى الـ bedrock)، مدى 10 بلوكات بدل 6، طيران وnoclip، وما في صحة ولا جوع ولا وقعات.

الأشياء هاي جمعتها من بحث عن الـ creative mode بألعاب الـ voxel sandbox (Luanti/Minetest، Vintage Story، Terasology، وغيرها) واخترت الشي المشترك بينهم، بتصاميم ومحتوى أصلي.

| التبويب | شو فيه |

| building | ألواح الخشب الثلاثة، cobblestone عادي ومطحلب، طوب، stone bricks، sandstone bricks، بلاط، جبس، زجاج، بلوكات معادن (حديد، نحاس، دهب، برونز، ألماس)، و **slabs و stairs** من 9 مواد |
| colored | صوف و زجاج ملوّن بـ 16 لون |
| plants | عشب طويل، سرخس، 4 ورود، فطر أحمر وبني، قصب، صبّار |
| functional | شعلة، لمبة، صندوق (بيخزّن 27 خانة)، طاولة شغل، فرن، رف كتب، سلم (بتطلع عليه)، باب (بيفتح وبيسكّر)، سياج (بيتوصّل لحاله)، تخت (بيحدد مكان الإحياء وبينيّمك لليوم الجاي) |
| tools | معول، فاس، مجرفة، سيف بـ 4 مستويات (خشب، حجر، حديد، ألماس)، وسطل (بيشيل المي وبيكبّها) |

**العالم صار فيه:** صحاري برمل وsandstone وصبّار، قمم جبال بتلج وصنوبر، غابات بتولا، قاع بحر فيه طين وحصى، صخور مختلفة تحت الأرض، معادن حسب العمق (الألماس تحت مستوى 9، الدهب تحت 14)، وعشب وورود وسرخس وقصب جنب المي.

## Survival: الأدوات والصنع

**مستويات الأدوات:** كل بلوك صلب بيحتاج مستوى أداة معيّن عشان يعطي شي:

| البلوك | أقل أداة |
|---|---|
| حجر، فحم، نحاس، قصدير، طوب | معول خشب |
| حديد خام، بلوك حديد/برونز | معول حجر |
| دهب، ألماس | معول حديد |

السرعة: خشب ×2، حجر ×4، حديد ×6، ألماس ×8. الاستعمالات: 60، 130، 250، 1500. المجرفة للتراب والرمل والحصى والطين والتلج. السيف أقوى ضربة.

**الـ crafting** (81 وصفة) فيها بحث وصفحات، واللي بتقدر تعمله بيطلع أول. "any planks" يعني أي نوع ألواح. أمثلة:

| الوصفة | النتيجة |
|---|---|
| 1 جذع | 4 ألواح من نفس الشجرة |
| 1 فحم + 1 عصاية | 4 شعلات |
| 1 خام + 1 فحم | سبيكة (صهر) |
| 3 نحاس + 1 قصدير | 4 برونز |
| 9 سبائك ↔ 1 بلوك | تخزين |
| 3 مادة → 6 slabs، 6 مادة → 4 stairs | |
| 3 مادة + 2 عصي | معول (وفاس 2+2، مجرفة 1+2، سيف 2+1) |
| 8 ألواح / 8 cobblestone / 4 ألواح | صندوق / فرن / طاولة شغل |
| 7 عصي / 6 ألواح / 4 عصي + 2 ألواح | 3 سلالم / باب / 3 سياج |
| 3 صوف + 3 ألواح | تخت |
| 3 حديد | سطل |

الحجر صار يعطي cobblestone (ورجّعه حجر بالفحم)، والوصفات كلها بـ `RECIPES` بـ `inventory.py`.

## الحيوانات

فيه 3 حيوانات بتتحرك بالعالم وبتظهر حواليك (لحد 12 بنفس الوقت)، والبعيدة بتختفي:

| الحيوان | وين بتلاقيه | شو بيعمل |
|---|---|---|
| أرنب | عالعشب | بينطّ، سريع، وبيهرب إذا قرّبت عليه 5 بلوكات |
| غزال | عالعشب | بيمشي على مهل، وبيهرب إذا قرّبت كتير |
| بطة | عالشط وعالمي | بتعوم فوق المي |

كل حيوان بيوقف شوي، بعدين بيمشي لمكان عشوائي، بيطلع درجة بلوك وحدة، وما بيمشي بالمي أو يوقع من علو (إلا البطة). إذا ضربته بيحمرّ وبيقفز لورا وبيهرب، وإذا خلصت صحته بيموت وبيعطيك لحمة نية (الأرنب والبطة 3 صحة، الغزال 8). ضربة الإيد 1، المعول 2، الفاس 3 (خشب) أو 4 (حجر). بيعتموا بالليل وبالظل متل البلوكات.

## الصحة والجوع

فوق الشريط فيه 10 قلوب (الصحة) و 10 أفخاذ (الجوع)، كل وحدة = نقطتين من 20.

- **الجوع** بينزل شوي شوي مع الوقت، وأسرع لما تمشي، تنط، تكسّر أو تضرب. الشريط المليان بيكفي تقريباً 20 دقيقة لعب.
- **الصحة بترجع** لحالها (نقطة كل 4 ثواني) إذا جوعك 18 أو أكتر.
- **الأذى:** الوقعة من أعلى من 3 بلوكات (المي بتلقطك)، الغرق لما يخلص نفَسك (10 ثواني، وبتشوف فقاعات)، والجوع لما يوصل صفر.
- **الأكل:** امسكه وكبس كليك يمين.

| الأكل | بيرجّع |
|---|---|
| لحمة نية (من الحيوانات) | 2 |
| تفاحة (أحياناً من الورق) | 4 |
| لحمة مطبوخة (2 لحمة نية + 1 فحم) | 6 |

لما تموت بتطلعلك شاشة فيها السبب، وبتكبس R لترجع بنقطة البداية بصحة وجوع كاملين. الـ inventory بيضل معك.
الأرقام كلها بـ `survival.py`.
السلوك بـ `animals.py` (`SPECIES` للسرعة والحجم ومسافة الهروب)، والأشكال بـ `animal_models.py`.

الحفظ بخزّن الـ seed والوقت والـ inventory والصحة والجوع ومكانك وتعديلات اللاعب بس، فالتعديلات بترجع لما ترجع لنفس المكان.

إعدادات بأول `main.py`: `RENDER_DISTANCE` (كم chunk حواليك بتنرسم) و `CHUNKS_PER_FRAME`.

## البنية / Structure

- `blocks.py` — **سجل البلوكات**: الاسم، الصور، الشكل، الصلابة، الأداة، شو بيعطي، والتبويب. لتضيف بلوك جديد بتضيف سطر هون.
- `world.py` — توليد العالم اللا نهائي (تضاريس، biomes، صخور، معادن، كهوف، شجر، نباتات)، الإضاءة، بناء الـ mesh لكل شكل، تصويب البلوكات (voxel raycast)، والحفظ.
- `inventory.py` — الأغراض، الأدوات ومستوياتها، قائمة الـ creative، الوصفات، والـ inventory.
- `schematics.py` — حفظ وقراءة ملفات البنايات.
- `building.py` — أدوات البناء بالجملة: التحديد، التعبئة، النسخ واللصق، التدوير، والتراجع.
- `survival.py` — الصحة والجوع والنفَس والوقعات والموت.
- `animals.py` / `animal_models.py` — سلوك الحيوانات وأشكالها.
- `textures.py` — كل الصور بترسم بالكود (pixel art أصلي).
- `lighting.py` — الـ shader اللي بيدمج الضو مع وقت النهار.
- `main.py` — اللعبة: العرض، اللاعب، الشاشات، التفاعل.
- `tests/` — 81 اختبار (`pip install -r requirements-dev.txt && pytest`).

العالم مقسوم لـ chunks حجمها 16×16 بتتولد من الـ seed لما تقرّب منها. كل chunk إلها 4 meshes: صلب، شفاف ملوّن، مي، ونباتات (بتمرق منها). الحفظ بخزّن الـ seed والتعديلات والصناديق والوقت والـ inventory والصحة والوضع والشرائط المحفوظة ومكانك ومكان الإحياء.

## Textures

الـ textures بتنرسم تلقائياً. إذا بدك ترسم تبعتك:

```bash
python textures.py      # بيطلع textures/atlas.png
```

عدّل الصورة بأي برنامج رسم (حافظ على شبكة 12×12 وترتيب `TILES` بـ `world.py`)، واللعبة رح تستخدم نسختك تلقائياً.
