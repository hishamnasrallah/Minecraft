# BlockWorld — نسخة جودو (للأندرويد والكمبيوتر)

نفس اللعبة بمحرك [Godot 4.3](https://godotengine.org)، عشان تشتغل على **الموبايل** (أندرويد، ولاحقاً آيفون) والكمبيوتر.

## تنزيل التطبيق على الموبايل (بدون لابتوب)

كل ما يتغيّر شي بمجلد `godot/`، **GitHub بيبني ملف التثبيت (APK) لحاله** وبيحطّه هون:

**https://github.com/hishamnasrallah/Minecraft/releases/tag/apk-latest**

افتح الرابط من الموبايل (وإنت داخل على حسابك بـ GitHub)، نزّل `BlockWorld.apk`، وثبّته. أول مرة الموبايل رح يطلب تسمح بالتثبيت من مصادر غير معروفة.

البناء **يدوي**: بينبني لما تكون نسخة جاهزة للتجربة (من تبويب **Actions** ← Android APK ← Run workflow)، وبياخد حوالي دقيقتين.

**إذا التطبيق سكّر فجأة:** بالمرة الجاية بيطلعلك وين وقف، وبيشتغل **بالوضع الآمن** (بدون شغل بالخلفية، ومسافة رؤية أقصر). ابعتلي الجملة اللي بتطلع. بتقدر تطفي الوضع الآمن من الإعدادات.

## شو فيها

- العالم اللا نهائي **نفسه بالضبط** متل نسخة بايثون (اختبار بيتأكد إنه بلوك ببلوك نفس الشي)، بكل أنواع الأرض والكهوف والمي والمعادن.
- الإضاءة والليل والنهار.
- **Survival:** صحة وجوع ونفَس ووقعات وموت، أدوات بمستوياتها وسرعة كسر، 81 وصفة صنع، أكل.
- **Creative:** قائمة فيها كل الأغراض بتبويبات وبحث، طيران، تكسير فوري، شرائط محفوظة، تحكم بالوقت.
- **حيوانات:** أرانب وغزلان وبط بيمشوا وبيهربوا وبيعطوا لحمة.
- أبواب بتفتح، صناديق بتخزّن، تخت بيحدد مكان الإحياء، سلالم، سطل مي.
- **أدوات البناء** وملفات البنايات (نفس صيغة نسخة الكمبيوتر، فيك تنقلها بين النسختين).
- حفظ تلقائي كل دقيقة، ولما تطلع من التطبيق.
- البناء والإضاءة بالخلفية، فاللعبة ما بتعلق.

## القائمة الرئيسية والعوالم

- أول ما تفتح التطبيق بتطلعلك **قائمة**: عوالمك (آخر واحد لعبته فوق) وزر **عالم جديد**.
- العالم الجديد: اسم، رقم (اختياري، نفس الرقم = نفس العالم)، ونجاة أو إبداع.
- كل عالم إله حفظه لحاله، وبتقدر تمسح أي عالم (بيسألك أول).
- جوا اللعبة: الإعدادات ← **احفظ وارجع للقائمة**.
- الحفظ القديم بينتقل لحاله كأول عالم.

## الأصوات

تكسير بصوت حسب المادة (حجر، تراب، خشب، زجاج، ورق)، وضع، خطوات، رشة مي، ضرر، أكل، وصوت لما تصنع شي. كلها مولّدة بالكود (`sounds.py`)، وبتتحكم بعلوها من الإعدادات.

## اللغة والإعدادات

- اللعبة **بالعربي أو بالإنجليزي**: بتختار العربي تلقائياً إذا لغة موبايلك عربي. بتغيّرها من زر **الإعدادات** (الترس فوق)، أو F2 على الكمبيوتر.
- كل أسماء البلوكات والأغراض مترجمة، والبحث بيشتغل بالعربي والإنجليزي.
- الأزرار عليها **أيقونات** وكلمة صغيرة تحتها.
- بالإعدادات كمان: **حساسية النظر**، و**مسافة الرؤية** (قلّلها إذا الموبايل بطيء)، وإظهار عداد السرعة (FPS).
- الخط: [Cairo](https://github.com/Gue3bara/Cairo) (رخصة OFL، بمجلد `fonts/`).

## التحكم

| | الموبايل | الكمبيوتر |
|---|---|---|
| حركة | عصا بتطلع وين ما تحط إصبعك باليسار | WASD |
| نظر | اسحب باليمين | الماوس |
| قفز | زر القفز (وبتطلع درجة وحدة لحالك) | Space |
| كسر / ضرب حيوان | ضغط مطوّل على زر المعول | ضغط مطوّل كليك يسار |
| وضع / فتح / أكل | زر المكعب | كليك يمين |
| الأغراض والصنع | زر الشبكة | E |
| اختيار من الشريط | اضغط عليه | 1-9 أو العجلة |
| طيران (إبداع) | زر الجناح، وبعدين فوق وتحت | دبل Space، و Shift للنزول |
| أدوات البناء (إبداع) | زر الشاكوش | Z X F H C V R M U Q L |
| تبديل creative / survival | زر بشاشة الأغراض | G |
| حفظ | زر الحفظ | F5 |
| الإعدادات | زر الترس | F2 |

**بشاشة الأغراض:** اضغط على خانة لتشيل الغرض، واضغط على خانة تانية لتحطه. زر **نص** بيخليك تشيل نص الكمية أو تحط وحدة. زر **سريع** بينقل الغرض مباشرة (بين الشريط والمخزن أو الصندوق)، أو بيصنع 16 مرة، أو بيضيف من قائمة الإبداع مباشرة.

**أدوات البناء على الموبايل:** أشّر على بلوك واكبس **Corner 1**، أشّر على بلوك تاني واكبس **Corner 2**، بعدين **Fill** أو **Hollow**... للصق: **Paste** مرة (بتشوف مكانه بالأصفر)، أشّر وين بدك، و **Paste** كمان مرة.

## تجربتها على الكمبيوتر

1. نزّل [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) (النسخة العادية، مش .NET).
2. افتح Godot → Import → اختار ملف `godot/project.godot`.
3. كبس ▶ (F5).

لتشوف أزرار الموبايل على الكمبيوتر: Project → Project Settings → General → Editor → Run → Main Run Args: `-- --touch`

## تطليع ملف APK للأندرويد

1. بـ Godot: **Editor → Manage Export Templates → Download and Install**.
2. نزّل **Android Studio** (أو Android SDK و JDK 17 بس).
3. بـ Godot: **Editor → Editor Settings → Export → Android**: حط مسار Java SDK و Android SDK.
4. **Project → Export → Android** (الإعدادات جاهزة بالمشروع) → **Export Project** → بيطلعلك `build/BlockWorld.apk`.
5. ابعت الملف للموبايل ونزّله (لازم تسمح بتثبيت التطبيقات من مصادر غير معروفة).

أو وصّل الموبايل بكيبل USB مع تفعيل "تصحيح USB"، وبيطلع زر أندرويد فوق بـ Godot بيثبّتها وبيشغّلها مباشرة.

## البيانات المشتركة مع نسخة بايثون

سجل البلوكات والأغراض والوصفات والصور كلها بتنصدّر من نسخة بايثون:

```bash
python tools/export_godot.py
```

بيكتب `godot/data/` (blocks.json, items.json, atlas.png) وعيّنات الاختبار. يعني لما تضيف بلوك بـ `blocks.py` بتصدّر وبيصير موجود بالنسختين.

## الملفات

- `scripts/vnoise.gd` — الـ noise، مطابق لبايثون.
- `scripts/world_data.gd` — العالم: التوليد، التعديل، الضو، التصويب، الحفظ (نفس صيغة ملف بايثون).
- `scripts/mesher.gd` — بناء الأشكال والإضاءة لكل chunk.
- `scripts/chunk_manager.gd` — تحميل الـ chunks حوالين اللاعب بالخلفية.
- `scripts/player.gd` — اللاعب والفيزياء.
- `scripts/touch_controls.gd` — تحكم الموبايل (multi-touch).
- `scripts/hud.gd` — الشريط والساعة والرسائل.
- `scripts/main.gd` — اللعبة.
- `shaders/` — الإضاءة والشفافية.
- `tests/` — اختبارات: `godot --headless --path godot -s res://tests/run_tests.gd`

## الملفات الجديدة بالمرحلة التانية

- `scripts/items.gd`, `scripts/inventory.gd` — الأغراض والأدوات والوصفات والـ inventory.
- `scripts/survival.gd` — الصحة والجوع.
- `scripts/animals.gd`, `scripts/animal_view.gd` — الحيوانات.
- `scripts/building.gd`, `scripts/schematics.gd`, `scripts/build_panel.gd` — أدوات البناء والملفات.
- `scripts/inventory_screen.gd` — شاشة الأغراض (crafting، creative، صندوق).
- `scripts/i18n.gd`, `scripts/settings_screen.gd` — اللغات والإعدادات.
- الترجمات من `i18n.py` والأيقونات من `ui_icons.py` (بنسخة بايثون)، بتنصدّر بـ `python tools/export_godot.py`.
